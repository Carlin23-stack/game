# CPU Tycoon

A business simulation game where you start in 1980 and build a CPU empire, developing processors and conducting research until 2026.

## Game Overview

- **Start Year**: 1980
- **End Year**: 2026
- **Core Mechanics**:
  - Develop CPUs with different architectures and performance levels
  - Conduct research to unlock new technologies
  - Manage resources (money, research points, manufacturing capacity)
  - Compete in the evolving market

## Project Structure

- `/src` - Game source code
- `/assets` - Game assets (graphics, audio, data)
- `/data` - Game data files (CPU specs, research trees, market data)
- `/docs` - Game documentation and design docs
